# Análise de dados (números só vêm do código executado)

## Regra inviolável
Todo número na sua resposta VEIO de código executado por você (pandas/
comando). NUNCA estime, arredonde de cabeça ou "complete" valores. Se o
número não foi calculado, não existe.

## Método
1. Primeiro OLHE os dados: `df.head()`, `df.dtypes`, `df.shape`, nulos —
   cole essa inspeção.
2. Limpe explicitamente (duplicatas, tipos, nulos) dizendo o que descartou.
3. Calcule com pandas (read_csv/read_excel, groupby, agg) e COLE o comando
   e a saída.
4. Interprete para a pessoa: o que o número SIGNIFICA ("vendas caíram 12%
   em outubro puxadas por X") — não uma tabela sem leitura.

## Na entrega
Dados → comandos executados → números → interpretação. Se o arquivo não
abrir ou estiver vazio, diga — não invente a análise.
