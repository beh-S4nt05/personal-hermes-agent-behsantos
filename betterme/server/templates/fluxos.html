🔧 Integração nos 2 sentidos (Betterme ↔ n8n)
• Do chat do Betterme: peça "quais são meus fluxos?" — a ferramenta fluxos_listar mostra os workflows e seus paths — e "dispare o fluxo X" — a ferramenta fluxos_chamar faz POST no webhook local (espere a resposta com o nó "Respond to Webhook").
• Do n8n: nó HTTP em POST para http://127.0.0.1:8080/api/hooks/<id> — crie uma tarefa agendada tipo webhook no Betterme (aba Tarefas) e o n8n dispara o agente quando o fluxo quiser.
• Listar workflows: betterme fluxos apikey <chave> (crie a chave no editor: Settings → n8n API) e betterme fluxos listar.
📖 Passo a passo — do zero à automação (templates prontos para importar)
  1. Instalar: betterme fluxos setup — precisa do Node.js 20.19–24.x na máquina (tudo de uma vez: python install.py --full).
  2. Subir: betterme fluxos start · na primeira vez o editor pede uma conta local (e-mail/senha ficam na sua máquina).
  3. Primeiro fluxo: copie o Template A abaixo → no editor, menu ⋯ → Import from clipboard → cole → ative o toggle Active (workflow inativo responde 404).
  4. Teste do chat: peça ao Betterme "dispare o fluxo betterme-eco" — a resposta do n8n volta na conversa.
  5. API do n8n: no editor, Settings → n8n API → criar chave → betterme fluxos apikey <chave> → betterme fluxos listar.
  6. n8n → Betterme: crie uma tarefa com gatilho webhook (aba Tarefas), importe o Template B e troque a URL do nó HTTP pelo /api/hooks/<id> da tarefa — o n8n dispara o cérebro quando o fluxo quiser (por horário? troque o 1º nó por um Schedule Trigger).
  7. Guia completo com troubleshooting: N8N_PASSOAPASSO.md (acompanha o zip e o repo).
